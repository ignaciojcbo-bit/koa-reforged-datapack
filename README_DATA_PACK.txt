KOA Reforged data pack (v1.4.0)
===============================

Adds 165 clothing items (Transmog outfits) and bigger stacks (181 consumables
stack to 99) to the game's data\patch_0.pak, using the official pak tools in
the game's modding folder. Nothing is removed or replaced.

Install:   close the game, run 2_build.bat (needs about 5 GB free, a few minutes).
Status:    1_status.bat
Uninstall: 3_undo.bat (game closed). FIRST turn every outfit look back
           (Transmog > Original look), stash included: a save that holds an
           item whose type no longer exists can crash at a merchant.

Your original pak is kept as patch_0.original.pak in this folder - keep it.
After a game update, run 2_build.bat again.
Every step is logged to koar_data_log.txt.
Full details: KOA_Reforged_README.md, section "Data pack".
